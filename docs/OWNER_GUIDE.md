# Руководство владельца сервиса

## Роли и вход

В сервисе две рабочие роли и одна форма входа для каждой роли:

```text
Администратор -> /admin -> логин администратора -> вся система
Партнёр       -> /partner/login -> логин магазина -> только данные магазина
```

Закрытый preview-пароль публичного сайта не является входом в админку. Он нужен только для просмотра тестовой витрины до открытого запуска.

## Что делает администратор

Администратор управляет всем сервисом:

- видит всех партнёров, точки и пользователей магазинов;
- подключает нового партнёра и выдаёт ему логин;
- может временно отключить партнёра, точку или сотрудника;
- видит и при необходимости создаёт предложения;
- видит все брони и коды;
- обрабатывает заявки с `/partners` и обращения с `/contacts`.

## Как подключить нового партнёра

1. Откройте `/admin` и войдите как администратор.
2. Откройте вкладку `Партнёры`.
3. В блоке `Подключить нового партнёра` заполните:
   - организацию;
   - первую точку;
   - логин и временный пароль владельца.
4. Нажмите `Создать партнёра и кабинет`.
5. Передайте владельцу магазина URL `/partner/login`, созданный логин и временный пароль.

Одна операция создаёт партнёра, адрес и кабинет вместе. Пароль сохраняется только как PBKDF2 hash + salt.

Если партнёр сначала отправил заявку на странице `/partners`:

1. Откройте `Заявки партнёров`.
2. Нажмите `Подключить`.
3. Система перенесёт реквизиты заявки в форму подключения.
4. Задайте логин и временный пароль.
5. Нажмите `Создать партнёра и кабинет`.

## Кто добавляет адреса

- Первую точку создаёт администратор при подключении.
- Вторую и последующие точки партнёр может добавить сам во вкладке `Адреса`.
- Администратор также может добавить дополнительную точку через блок `Дополнительные адреса и сотрудники`.
- Администратор может отключить точку. Предложения отключённой точки не показываются покупателям.

## Кто создаёт предложения

Основной сценарий: партнёр сам нажимает `Разместить сегодня`, фотографирует текущую партию, указывает название, цену, время и количество, затем публикует предложение.

Администраторская форма `Предложения` нужна для первого запуска, поддержки или исправления ошибки. Активное предложение на сегодняшнюю дату сразу появляется на главной, если партнёр и точка включены и остаток больше нуля.

## Как работает код

```text
Покупатель выбирает предложение
  -> вводит имя и телефон
  -> сервер создаёт уникальный BS-XXXX
  -> остаток уменьшается на 1
  -> код видят администратор и только соответствующий партнёр
  -> партнёр отмечает: Выдан / Не пришёл / Отменён
  -> новый статус сразу виден администратору
```

Оплата остаётся на кассе партнёра. Сервис не принимает оплату за еду.

## Разделы админки

- `Обзор` — показатели и короткий рабочий порядок.
- `Партнёры` — подключение, точки, сотрудники и отключение доступа.
- `Предложения` — все предложения и их публикация/пауза.
- `Брони и коды` — все коды и статусы выдачи.
- `Заявки партнёров` — входящие заявки на подключение.
- `Обращения` — сообщения со страницы контактов.
- `Настройки` — сведения о хранилище и сервисные проверки.

## Разделы кабинета партнёра

- `Обзор` — состояние текущих предложений и кодов.
- `Адреса` — только точки этого партнёра.
- `Предложения` — быстрая публикация с фото и управление остатками.
- `Коды и брони` — только коды этого партнёра.
- `Профиль` — контактные данные организации.
- `Помощь` — подсказка по выдаче.

Партнёр не может изменить `partner_id` и не может получить чужие адреса, предложения, изображения или брони через API.

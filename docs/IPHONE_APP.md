# «Бери сегодня» на iPhone

Ссылка для инструкций и QR-кодов: https://berisegodnya.ru/install. Она подходит и для Android, и для iPhone.

## Как установить

1. На iPhone откройте ссылку в Safari и выберите «Установить на iPhone».
2. Нажмите «Открыть приложение».
3. Нажмите «Поделиться» → «На экран Домой». Если есть переключатель «Открыть как веб-приложение», включите его. Нажмите «Добавить».
4. Откройте «Бери сегодня» с новой иконки на экране телефона.

Это веб-приложение, установленное на экран «Домой», а не приложение из App Store. Оно открывает отдельный интерфейс с нижним меню. Для бронирования и свежих остатков нужен интернет. При обрыве связи нельзя считать набор забронированным, пока сервер не подтвердил бронь и не выдал код.

## Как забронировать

Откройте «Предложения» внизу. Нажмите понравившийся набор. Проверьте состав, цену, адрес и время выдачи. Нажмите «Забронировать» или «Получить код», укажите имя и телефон, подтвердите согласие и получите код. Оплатите в магазине при получении.

Регистрация для первой и следующих броней не обязательна. Без кабинета новые брони, оформленные в этом веб-приложении, доступны в «Моих бронях» на этом устройстве. После очистки данных браузера сохранённые ссылки могут пропасть: сохраните ссылку на бронь отдельно. Старую бронь с сайта можно открыть по её ссылке; все старые гостевые брони автоматически не переносятся. Safari и установленное веб-приложение могут иметь отдельные данные и сессии.

Чтобы не вводить имя и телефон заново и видеть историю на разных устройствах, откройте «Профиль», войдите по коду из письма и сохраните контакты. Брони после входа появятся в этом кабинете и на сайте, и в Android. Последнюю гостевую бронь можно добавить кнопкой в кабинете, если она сохранена на этом устройстве; перед добавлением нужно подтвердить действие.

После входа предлагаем короткое обучение: выбор набора, получение кода и поиск своей брони. Можно нажать «Позже». В «Профиле» есть кнопка «Как забронировать», чтобы посмотреть ещё раз. Отметка о просмотре хранится только на этом устройстве, а не в аккаунте.

## Заведение и администратор

Внизу откройте «Партнёрам» → «Вход для партнёра». Это отдельный вход с логином и паролем, выданными при подключении. Для владельца и менеджера доступны «Предложения», «Коды», «Кабинет», «Ещё». У продавца только разрешённые ему разделы.

В разделе «Партнёрам» также есть «Вход для администратора». После входа внизу доступны «Обзор», «Заведения», «Брони», «Ещё». Админский доступ не передают сотрудникам заведений. При обязательной смене временного пароля сначала нужно установить новый пароль.

## Техническая граница релиза

- `/app` — отдельный интерфейс покупателя; `/app/bookings`, `/app/profile`, `/app/partners` — его разделы.
- Приватные кабинеты и страницы броней сохраняют режим приложения через `app=1`. Права проверяет прежний сервер, параметры URL не дают доступа.
- Manifest сохраняет прежний `id: /` и scope, но запускает `/app?source=pwa`. Ранее установленные ярлыки главной перенаправляются только в standalone-режиме.
- Обычная главная остаётся сайтом. APK 0.3, его подпись и ссылки на прежние версии не меняются.
- Остатки, профили и статусы броней берутся с сервера. LocalStorage содержит только ограниченный список гостевых ссылок и отметку об обучении. История кабинета, контакты и коды в новое хранилище не записываются.
- Service worker не сохраняет HTML/ответы API/приватные данные. Офлайн-экран сообщает об отсутствии соединения. Не обещаем оформление заказа без сети.
- Проверки Node/браузера не заменяют установку с Safari на настоящий iPhone. Приёмка на реальном iPhone — отдельный незакрытый пункт. Это изменение не является новой сборкой Android; обучение в его нативных экранах потребует отдельного выпуска APK.

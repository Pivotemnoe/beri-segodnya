# Проверка отдельного веб-приложения, 10 октября 2026

## Проверено до выкладки

Локальный Node **24.19.0** из готового runtime Codex. Изолированные временные базы, без рабочих заказов и реальных контактов.

- Build/syntax и неизменность подписанного APK 0.3.
- Security gate, 118 auth-boundary checks, 74 customer-email checks.
- API smoke: уникальные коды, ограниченный остаток, повтор запроса, отмена, роли и изоляция заведений.
- Request boundaries, upload quota, backup/restore.
- Новые маршруты, assets, CSP, `method=post` у форм профиля, закрытый preview gate, прежний manifest id и новый start URL.
- Клиентские unit checks: ссылки только своего origin, ограничение 20 гостевых ссылок, дедупликация, повреждённое хранилище, сохранение ссылки при сетевой ошибке, отсутствие контактов/кодов/истории кабинета в новом localStorage, opt-in onboarding.

Chrome, размеры **390×844** и **430×932**:

- Каталог → карточка → гостевая форма → код → страница брони с нижним меню → «Мои брони». Остаток уменьшился с 8 до 7 в учебной базе; обязательной регистрации нет.
- Три шага обучения, подсветка «Моих броней», пропуск и повтор из профиля.
- Владелец: вход, «Предложения», «Коды», «Кабинет», дополнительное меню, сохранение `app=1` при переключении вкладок.
- Продавец: только «Коды» и «Ещё», без публикации предложения.
- Администратор: отдельный вход, «Обзор», «Заведения», «Брони», дополнительное меню. Проверен также обязательный экран смены временного пароля; для проверки навигации использован заранее подготовленный учебный профиль с постоянным паролем.
- Страница установки содержит Android и iPhone, общий QR и прямую ссылку на действующий APK. Маркетинговый подвал со страницы установки убран.
- Горизонтальная прокрутка не обнаружена в проверенных мобильных кабинетах.

## Не выдавать за проверенное

- Установка из Safari на физический iPhone, запуск с иконки и поведение его настоящей клавиатуры пока **не проверены**.
- Приёмка Chrome на размерах телефона не является приёмкой Safari или APK.
- Нативный APK 0.3 этим релизом не пересобирается; новое обучение относится к веб-приложению. Обновление нативных экранов требует отдельного подписанного выпуска.
- Учебный профиль не доказывает готовность юридических документов и массовой рекламной кампании.

Выкладка допускается только после новой зелёной CI-проверки PR. Данные, `.env.local`, ключи и APK сохраняются. Результат выкладки фиксируется отдельно после postflight, а не этим предварительным протоколом.

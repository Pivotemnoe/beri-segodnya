# Кабинет покупателя — по желанию

Чтобы забрать первый заказ, регистрироваться не нужно. Выберите товар, нажмите «Забронировать», укажите имя и телефон для связи по заказу. Получите код, сохраните его и покажите сотруднику магазина. Оплата — в магазине.

Если планируете пользоваться сервисом дальше, откройте «Мой кабинет» на сайте или «Профиль» в приложении нового выпуска. Укажите почту, подтвердите согласие и нажмите «Получить код на почту». Введите шесть цифр из письма. Пароль придумывать не нужно. Если письма нет, проверьте «Спам»; повторную отправку можно запросить через минуту.

Сохраните своё имя и телефон. При следующих заказах, оформленных после входа, данные подставятся сами. Брони появятся в «Мои брони» на всех устройствах, где вы вошли по той же почте. Вы можете пользоваться только сайтом — устанавливать приложение необязательно.

Бронь, сделанная без кабинета, тоже действительна. Она не пропадёт из-за отсутствия регистрации. Сохраните её код и личную ссылку. Не пересылайте личную ссылку посторонним: по ней можно посмотреть и отменить бронь. Последнюю гостевую бронь на сайте можно добавить в кабинет отдельной кнопкой. Брони с одинаковым телефоном не собираются автоматически.

В кабинете можно изменить контакты, выйти или отправить в поддержку запрос на удаление. Запрос увидит администратор; сначала нужно проверить незавершённые заказы и правила хранения данных. Поддержка: support@berisegodnya.ru.

Для заведения и администратора остаются свои отдельные входы. Покупательская почта не даёт доступа к управлению товарами и чужими заказами.

Статус документа: инструкция для нового кандидата. Опубликованный Android 0.2 не содержит покупательского кабинета; перед распространением 0.3 обязательны сборка, подпись и проверка установленного APK.

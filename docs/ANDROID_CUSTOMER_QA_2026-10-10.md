# Покупательский кабинет: приёмка 10 октября

На рабочем сайте включён необязательный вход по коду на почту. Гостевая бронь остаётся доступной. SMTP проверен с самого VPS: TLS/сертификат, AUTH, доставка в Gmail, однократное принятие кода и отказ повтору. Серверный выпуск 0a117c1 прошёл изолированную репетицию, резервное копирование/реальное восстановление отдельно от рабочей базы и 14 проверок HTTPS. Приватные ключи и данные не публикуются.

На физическом TECNO CAMON 19 / Android 13 установлен подписанный кандидат 0.3. На момент этой записи подтверждены:

- реальный вход по письму (код ввёл владелец);
- сохранение нейтральных имени и контактного телефона из APK, отображение обоих на сайте под той же почтой;
- явный перенос только собственной учебной гостевой брони в общий кабинет; другая гостевая бронь осталась отдельно;
- новая учебная бронь с автозаполненными контактами и привязкой к кабинету; остаток 2 → 1;
- её отображение на сайте и сохранение сессии/истории после холодного запуска APK.

Проверка без сети выявила дефект: история кабинета показывала сохранённый код, но экран самой брони искал резервный код только в гостевой истории. Для этого добавлен общий выбор локального кода: гостевые коды доступны как прежде, коды кабинета — только при наличии покупательской сессии; код никогда не подтверждает актуальный статус. Чистые тесты проверяют гостя, кабинет, выход, неизвестный токен и пересечение списков.

Исправленный APK 9ef1fbb собран и подписан прежним ключом; installed base.apk совпал по SHA-256. На том же физическом телефоне повторный офлайн-тест прошёл: код кабинета виден на экране брони с предупреждением о непроверенном статусе. Связь возвращена в исходное состояние. Отмена своей учебной брони вернула остаток 1 → 2; выход убрал историю кабинета, сохранив гостевую.

Дополнительный облачный UI-тест 38025959915 обнаружил ошибку самой проверки, не DNS: API загрузил учебную карточку, но тест искал кнопку «Обновить» только в первом видимом экране. Тело ответа и карточка подтверждены в XML, network log пуст. Тест теперь прокручивает по свежему XML до той же обязательной кнопки и возвращается к заголовку для снимка. Условие успешного API не заменено допуском ошибки. Этот новый тест ещё должен пройти.

Повтор 38026672623 остановился на попытке вернуть верх каталога для снимка, до других экранов. Проверка теперь сохраняет начальный экран до прокрутки и отдельно экран найденной кнопки, включая доказательства при отказе. Прокрутка дольше и вне центра фотографии — такой жест уже сработал на реальном TECNO. Допуск сетевой ошибки не добавлен.

После выхода из кабинета на физическом APK поля гостевой брони пусты. Новая бронь с нейтральными контактами создана без регистрации и без customer_id; остаток 2 → 1. Она отменена из APK с возвратом 1 → 2. Новая бронь кабинета тоже отменена. Совпадение телефона не привязало гостевую бронь к аккаунту автоматически.

Публичная версия на момент записи остаётся 0.2; эта запись не является разрешением массового запуска. После приёмки необходимо скрыть только учебный набор и сверить неизменность существующих записей. Рабочие фото, история и резервная копия сохраняются.
